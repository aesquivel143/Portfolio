A web application developed in **Python** using **Streamlit** and **SQLite**, designed for multi-company inventory management featuring interactive reorder alerts via WhatsApp.
#### Key Features
- **Multi-Tenant Architecture:** Data isolation per company using `empresa_id`.
- **Stock & Reorder Alerts:** Dynamic reorder point calculation based on average sales and lead time, with interactive WhatsApp redirection buttons (`wa.me`).
- **Batch Traceability:** Batch number and expiration date tracking with 30-day expiration alerts.
- **QR Codes:** Automated QR code label generation per product with webcam or scanner support.
- **Professional Reporting:** Data export to Excel (`.xlsx`), CSV, and formal report/Purchase Order (PO) PDF generation via `ReportLab`.

### 4. ROI Simulator & Digital Marketing Budget Tool
An interactive web application built in **Python** and **Streamlit** designed for entrepreneurs, marketing specialists, and digital agencies. Allows users to project Return on Investment (ROI), analyze Cost Per Acquisition (CPA), and compute net profit considering payment gateway fee deductions and multi-currency support.
#### Key Features
- **Key Metrics Dashboard:** Automated calculation of Clicks, Sales, CPA, Gross Revenue, ROAS, and Net Profit.
- **Payment Gateway Fee Deduction:** Integrates percentage and fixed fee structures for platforms like Stripe, PayPal, and Mercado Pago.
- **Multi-Currency Support:** Compatible with **MXN, USD, EUR, COP, CLP, and ARS**.
- **A/B Scenario Comparison:** Side-by-side budget strategy evaluation to identify the most profitable path.
- **Interactive Break-Even Charts:** Dynamic break-even visualizations and cost breakdowns powered by **Plotly**.
- **Smart Diagnostics:** Conditional logic system issuing automated alerts for unprofitable campaigns or excessively high CPA margins.
- **Executive PDF Report:** Formal results export generated using the **ReportLab** library.
#### UI/UX Design
- **Theme:** Custom *Mint Green & Pastel Pink* palette implemented via custom CSS injection.
- **UX/UI Layout:** Parallel column layout with highlighted key metric cards and organized input controls.
